# 工作区界面原型

本原型用于评价 Movara 工作区的布局、主题、密度与基本操作反馈。界面采用预置路口和主体快照，运行按钮驱动演示时钟。主体位置保持固定。

## 生成与查看

在仓库根目录通过现有 Windows Bun 执行：

```bash
just ui-prototype
```

生成页面位于仓库内的 `.local/ui-prototype/index.html`，可直接在浏览器打开。页面包含所需样式、脚本和 SVG，支持离线查看。构建需要已有 Bun；本原型没有第三方包依赖。

可比较浅色与深色主题、标准 A 与紧凑 B 密度；可选择主体、筛选列表、切换参考路线与网格，并操作演示时钟。菜单连接对应的工作区操作，窗口管理按钮用于展示布局。页面顶部持续标明原型身份，“显示说明”开关控制窗口外的设计说明区域，默认隐藏。应用窗口内采用产品文案，演示限制与设计解释统一写入外部说明区。

文件菜单提供内置场景加载与参数文件导入、导出。原型文件使用 `movara-ui-prototype` 标识与版本 2，保存示例主体的模型、目标速率及路口信号方案；正式场景格式按领域设计实现。无效文件在打开窗口内显示具体错误。已应用的参数修改通过标题栏标记，打开其他场景前确认未保存修改的处理。

导出操作发起浏览器下载，未保存标记继续保留。浏览器下载的完成情况由浏览器管理。打开新场景前同时检查未保存参数与未应用草稿，取消操作保留原有输入。

暂停且处于实时视图时可编辑所选主体的目标速率，输入错误保留草稿并显示原因。应用参数与当前实际速率分别呈现。本原型采用 0–50 m/s 作为表单校验样例，主体能力约束在实际应用中由内核提供。

行为模型下拉框演示遵循参考路线、保持停止与外部控制三种配置，目标速率按模型显示可用性。模型选择仅更新原型配置，主体快照保持固定。目的地、路线与轨迹关键点编辑按后续交互样例推进。

校园路口控制器可在交通设施列表或画布中选中。右侧提供当前相位、南北与东西绿灯时长、黄灯和全红间隔，关联字段统一校验与应用，灯色随应用的相位更新。配时与相位属于预览数据，实际控制周期与相位衔接尚未模拟。信号参数、模型与草稿随各运行分别保存。

视图菜单控制面板、图层和时间轴，支持场景缩放、适应与定位选择。画布可拖动平移，滚轮围绕指针缩放，比例尺同步更新。仿真菜单复用工具栏的运行与单步操作，重置和结束通过确认对话框执行。菜单支持鼠标、方向键与 Escape，快捷键通过帮助菜单查看。

顶部“情境”选择用于比较等待控制提交、故障停止和正常结束。原因通过覆盖式通知与固定宽度状态入口呈现，通知可关闭并重新查看，主要分区保持原位。控制等待超过 1.2 秒后提示，同一运行的等待通知至少间隔 10 秒；两者为原型候选参数。界面提示阈值与控制回合的失败超时分别配置。返回自由操作后保持暂停。浏览历史保留当前运行的状态提示，创建新实验或切换运行后回到自由操作情境。

“加载场景（阻断）”情境在应用内容区覆盖半透明遮罩，直接显示等待文字并阻止内容区输入。创建实验对话框用于确认名称与分支时刻，在同一内容区居中。两种遮罩均覆盖标题栏下方的区域，自绘标题栏与原型审查工具保持独立。

画布左下角的历史图标展开半透明浮动时间条，按钮名称通过 tooltip 和无障碍标签提供。时间条可拖动时间、跳转示例事件、播放历史或返回实时。从历史创建实验会新增一条示例运行，保留原运行的时间范围；运行下拉框用于切换两者。该操作仅演示交互与本页临时状态，刷新页面后恢复初始数据。主体快照保持固定。

工具栏持续显示当前运行名称，并提供运行切换入口。各运行分别保留参数、输入草稿、事件与操作记录、结束或故障状态，切换时保持暂停。分支继承来源的示例参数以及分支时刻之前的记录，后续修改各自维护。所选历史时刻的完整世界恢复通过后续内核能力验证。

比例尺与历史入口在同一角落组合中排列，显示长度随 SVG 的实际缩放更新。各浮动工具共用材质规则。

图层按钮按区域宽度自动切换一列或两列，宽度不足时保持单列。隐藏侧栏时画布扩展，底部记录区保留原有行位置与高度。

参考路线、历史轨迹与未来轨迹分别提供开关，使用细虚线、淡色短虚线及实线区分。未选中主体使用低透明度的类别色，选中主体高亮并显示未来轨迹采样点。时间文字默认隐藏，可独立开启；时标相对当前观察帧，样例采用 +2 s 与 +4 s。历史与未来轨迹均为预设演示数据；真实轨迹与参考路线的空间几何分别提供。

右侧与底部共用选项卡组件。底部可切换事件与操作记录，右侧从属性页开始扩展。选项卡支持点击、方向键与 Home/End，页面独立滚动并保留状态。

## 源码与资产

| 文件 | 职责 |
| --- | --- |
| `render.ts` | JSX 节点、函数组件与 HTML/SVG 静态序列化 |
| `workspace.tsx` | 工作区组件、示例数据与路网 SVG |
| `components.tsx` | 按钮、图标、字段与选项卡等共享组件 |
| `chrome.tsx` | 标题栏、覆盖式运行通知与阻断覆盖层 |
| `menus.tsx` | 菜单分组、命令入口与快捷键标签 |
| `dialogs.tsx` | 加载、确认与帮助对话框 |
| `signals.tsx` / `signals.js` | 信号灯、设施选择、相位与配时表单及其预览交互 |
| `style.css` | 布局、密度和组件外观 |
| `interactions.js` | 浏览器中的选择、显示选项与演示时钟 |
| `workbench.js` | 菜单命令、场景参数、编辑草稿与画布操作 |
| `build.ts` | 读取颜色参数并生成独立 HTML |
| `tsconfig.json` | 指定自定义 JSX 工厂与片段函数 |

TSX 通过自定义 `h` 工厂构造节点，渲染器将节点序列化为静态标记。HTML/CSS 负责面板与文字布局，SVG 负责空间场景。重复元素使用函数组件与数据列表组织。渲染器转义文本和属性，浏览器交互由独立脚本绑定。

颜色从[设计参数](../tokens.md)的颜色表读取，密度尺寸按该文档在 CSS 中成组定义。修改尺寸时同步维护参数表与原型。场景数据配色独立于界面语义颜色。

源码作为应用设计资产纳入版本管理。生成 HTML、截图与评价记录保存在已忽略的 `.local/`。原型独立于应用运行代码，正式桌面界面使用 Rust 技术栈。静态序列化覆盖本原型使用的标签、属性和组件；前端应用的状态框架与通用模板能力不属于其范围。

## 审查方式

优先在 1440 × 900 和 1600 × 1000 视口比较四种主题与密度组合，检查中文混排、属性单位、选中与焦点、事件列表和画布占比。浏览器缩放与系统缩放分别记录。

较窄窗口先收起对象面板，短窗口缩减事件区；布局用于评价候选方案。原生窗口拖动、缩放、输入法、仿真性能与真实客户端时序通过后续专项验证确定。
