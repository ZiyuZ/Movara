## 产品体验

Movara 面向自主式交通系统的多主体交互、交通管理和实验检查。主工作区以空间画布为中心，提供可持续观察的运行信息、明确的操作上下文和便于对照的数据表达。

界面同时服务直接操作与 Python 实验。GUI 作为进程内客户端，通过应用协调入口调用领域能力。界面控件按实际确认的运行状态和操作结果更新。

## 设计范围

应用采用自定义标题栏，保持平台窗口管理行为。基础工作区组织加载场景、运行与暂停、单步、选择主体、检查属性和查看事件。图层、参数编辑、观测信息及分析视图按对应功能阶段加入。

通用交互优先采用菜单、工具栏、搜索、属性编辑与参数配置。自定义策略和实验逻辑通过 Python API 表达。首轮不提供可视化脚本。命令面板作为低频操作检索的候选入口，常用控制直接可见。

HTML 原型用于比较布局、视觉参数和交互流程。界面原型使用模拟状态，并明确标记数据来源。正式应用采用的技术框架及其原生行为通过相应技术验证确定。
