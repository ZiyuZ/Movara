# 视觉与组件

Movara 的视觉语言服务于空间观察、实验控制和高密度信息检查。排版、对齐、间距和状态反馈共同建立层级，品牌形象使用项目既有燕子标志。整体采用科研工具的紧凑桌面语言，主画布、停靠面板与表格使用连续、平直的区域边界。圆角集中用于小型控件和浮层，普通数据区域不使用卡片包裹。装饰性大圆角、整窗渐变和持续背景动效不属于基础风格。

## 视觉层级与颜色

界面采用稳定的背景和低噪声的分隔，强调色用于选择、焦点与主要操作。圆角按控件和容器层级设置，阴影用于需要说明遮挡关系的浮层。普通面板可以通过间距、标题和分隔线形成分组。

基础界面使用中性灰白或中性深灰，青绿色主要表达交互强调、选择和焦点。大面积内容区域保持中性。画布中的地表颜色属于独立的数据表达。

画布、图表和正文数据区域保持可预测的底色。界面装饰、焦点变化与背景效果需要保持数据颜色的可辨识性。

| 颜色体系 | 表达内容 | 组合要求 |
| --- | --- | --- |
| 基础界面 | 背景、表面、正文、弱化信息与边界 | 明暗主题保留相同层级 |
| 交互 | 选中、悬停、按下、焦点与禁用 | 用颜色结合轮廓或位置表达状态 |
| 操作反馈 | 成功、信息、警告与错误 | 同时提供文本或图标含义 |
| 运行状态 | 运行、暂停、等待、故障与结束 | 使用准确状态词并保持稳定位置 |
| 空间数据 | 主体类别、通行区域、信号及选择覆盖层 | 保留图例和明确的显示优先级 |
| 分析数据 | 分类、连续数值和时间序列 | 提供量纲、范围与对应标度 |

交通信号的红色与界面错误颜色分属不同语义。连续数据色阶和对象类别色各自定义，选择高亮优先通过轮廓、线宽或外环表达。明暗主题分别检查数据图层叠加后的辨识度。

## 排版、密度与中文

界面说明采用适合中文与英文混排的无衬线字体，路径、代码和机器标识按需要使用等宽字体。数字表格优先采用便于纵向比较的数字排版，并明确单位及显示精度。

普通密度用于主要工具、表单与对话框，紧凑密度用于对象列表、属性、表格和日志。控件高度、内边距、图标尺寸及行高按密度共同调整。文字可读性与交互命中范围分别检查。

标签采用内容自适应布局，长路径和长标识提供完整查看与复制方式。中文术语、英文名称、负数、小数和单位共同参与排版评价。示例内容使用实际领域名称，例如“等待 Python 控制提交”“横向偏移”和“参考曲线方向”。

中文 IME 的组合文本、候选窗口、焦点切换、选择、粘贴及撤销属于基本输入行为。Enter 和 Escape 在组合输入期间按输入法状态处理，画布快捷键遵循焦点边界。

窗口缩放时保持主画布和必要运行信息可见，面板通过收缩、折叠或滚动适应可用空间。系统 DPI、文字缩放和布局密度分别评价，实际参数在原型中比较后确定。

## 参数与组件规范

具体尺寸、字体、颜色与调整方式见[设计参数](tokens.md)，按钮、输入、属性、面板和命令面板的行为见[组件与操作规则](components.md)。候选参数通过整套方案比较，局部页面遵守统一 Token。参数变更同步更新相关组件与原型。

高频更新采用稳定布局，可访问性评价覆盖键盘到达、焦点可见、文字对比、控件命名及颜色之外的状态提示。

## 交互原型评价

设计原型围绕加载场景、运行观察、选择主体、检查属性、暂停与单步、等待控制及故障检查形成完整流程。原型使用有领域含义的模拟数据，并区分世界真值、策略信息与操作反馈。

工作区原型与组件展示复用同一套设计参数。原型中的组件展示用于检查真实任务采用的控件及状态，复杂专用组件按已确定的功能范围补充。

| 评价内容 | 检查方式 |
| --- | --- |
| 信息层级 | 在画布、属性与事件之间完成定位和检查，辨识主要操作 |
| 运行反馈 | 比较运行、人工暂停、等待提交、故障和结束状态 |
| 中文与混排 | 使用长术语、中文搜索、长路径及带单位数值进行输入和布局检查 |
| 面板与焦点 | 调整、折叠和恢复面板，使用键盘完成主要操作 |
| 主题与密度 | 切换明暗主题和布局密度，检查图层及状态辨识度 |
| 窗口与缩放 | 在不同桌面窗口尺寸和缩放比例下检查布局与命中范围 |

HTML 原型可以检验浏览器中的交互、排版和组件组合。原生框架的输入法、字体回退、窗口行为、DPI 与实际绘图性能通过对应平台的技术验证确认。
