# 工程筹备计划

本计划组织设计讨论、技术验证与工程筹备。平台交付阶段见[路线图](ROADMAP.md)。已确定事项集中在下方结论表，具体能力按对应阶段验收。

当前阶段：**文档审查与界面设计研究**。界面规范和交互原型按讨论范围推进；依赖安装、具体技术验证和正式应用实现待整体审查后安排。

## 待推进事项

议题按下列顺序推进。需要产品选择的行为语义集中讨论；字段命名、符号和基础数据约定根据已确定原则直接维护，具体算法与参数通过验证确定。

### Agent 设计审查

- [ ] 审阅模型接入与任务草案，重点确认指令层次、平台与研究代码边界、决策时序、目标终态和外部恢复条件。
- [ ] 结合实际研究场景调整参考实现与验收范围，再纳入整体设计审查。

### 界面设计

- [ ] 审查工作区的菜单、场景加载与导出、参数校验、画布操作、运行状态与历史流程，以及主题、密度和中文表达。
- [ ] 补齐组件展示、面板调整与折叠恢复、世界状态与 Agent 观测比较等原型样例，按完整任务流程评价。
- [ ] 制作主体目的地、参考路线和轨迹关键点编辑的交互原型；细化信号方案的相位衔接与生效规则。
- [ ] 明确 egui 与 GPUI 的早期对比样例，评价桌面组件、中文输入、外观与开发成本；三维显示随后评估嵌入与独立查看器方案。

### 整体审查与后续执行

- [ ] 用户完整审查需求、设计、API、原型及验证计划，确认范围与预期。
- [ ] 根据审查意见修订文档，确认后续执行范围。
- [ ] 执行技术验证，记录实际结果并固定依赖、数值条件与采用结论。
- [ ] 补齐工程目录和开发命令，按审查后的任务推进实现。

具体版本、性能数据、数值阈值和算法效果依赖后续验证，文档中的计划不代表已取得相应结果。
