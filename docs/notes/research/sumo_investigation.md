# SUMO 交通管理能力评估

更新时间：2026-10-30。状态：官方文档初查、已确认缺陷与原始修复补丁核对，尚未安装或运行案例，也未复现用户历史失败。SUMO 是 Movara 的主要交通管理对照对象，Waymax、MetaDrive 等保留为局部参考。原型与具体测试按工程筹备结果安排。

## 1. 评估目标

先判断已有能力怎样满足实际任务，再决定直接使用、局部复用或自建。比较同时考虑正常交通、违规运动、接触、持续运行和配置维护成本。文档列出功能不足以证明该功能适合我们的组合场景，用户的使用困难也不能直接推断整个工具缺失能力。

Movara 的交通管理定位和统一 Agent 边界保持独立。Rust 与 GPUI Kit 仍是优先原型候选，SUMO 评估可以影响复用范围；当前未决定把 SUMO 作为运行内核，也不预建双内核系统。

## 2. 本轮文档证据与判断

| 范围 | 官方来源已确认什么 | 对 Movara 的判断与缺口 |
| --- | --- | --- |
| 地图输入 | OpenDRIVE 导入通过 netconvert 转为 SUMO 网络，车道类型映射影响导入 | 可参考转换与连接处理；检查源几何、ID、行人区域及信号信息变化 |
| 路径与持续交通 | Routing包含 flow/trip 路线分配、在线重规划及临时封闭处理 | 作为入口交通、路线和网络级绕行的重要参考；局部自由绕障另行核验 |
| 信号控制 | Traffic Lights提供内置信号、程序和外部控制方式 | 优先研究其交通语义与控制层划分，不直接复刻完整信号工具链 |
| 外部控制 | 车辆状态控制支持速度、加速度、换道等，执行受相应模式影响 | 区分模型输出、执行约束和接口覆盖；排查用户所需行为是否需反复绕过默认机制 |
| 库调用 | libsumo提供免 socket 的 C++ 接口与 Python 绑定 | Python 接入已有路径；Rust 绑定、并行和状态权威仍需评估，接口并不等于可独立拆出的模块 |
| 违规与事故 | Safety列出违规、碰撞判据和事故后处理选项 | 核验设置与几何接触的实际关系，不能直接把默认 collision 当成统一轮廓真值 |
| 连续与传送 | 传送说明解释实际传送及相关配置 | 测试时区分显示更新、连续运动与显式传送，记录配置 |
| 行人 | Pedestrians说明路网、共享空间、模型与额外可步行区域 | 核验路中横穿、自由选择位置、有限观测和车人闭环；不把“能移动到某点”当成完整策略 |

libsumo 与 sumo-gui 的集成存在官方列出的平台限制，不能据此断言独立桌面读取状态不可行。GUI、嵌入和批量实验的具体调用方式需单独验证。

## 3. 同场景验证矩阵

### 已找到的相关缺陷

SUMO #16092报告了与用户描述高度相似的现象：通过 person.moveToXY 让行人违规横穿，车人重叠却未被 getCollisions 报告。维护者确认 Bug，2025-01-30 修复了车道宽度相关映射，并在行人遥控移动后请求车道碰撞检查。

已直接阅读修复补丁：映射距离考虑车道宽度、遥控行人移动后触发碰撞检查。后者在 MSPModel_Striping 的 moveToXY 中增加 lane->requireCollisionCheck()。1.22.0 更新记录包含车车/遥控行人漏检修复。

结论：已确认 SUMO 历史上存在相关映射和漏检缺陷，不能把用户遇到的困难简单归为配置问题。尚无用户当时版本、地图和脚本，未确认其具体失败就是此缺陷，也未本地复现。该证据不足以断言当前版本仍有同一 Bug，更不足以直接排除 SUMO 整体。

## 4. 怎样影响实现选择

| 路线 | 采用条件 |
| --- | --- |
| 直接使用或扩展 SUMO | 关键场景可可靠表达，控制与接触语义满足目标，适配成本可接受 |
| 复用工具或局部代码 | 地图转换、交通生成、路由等能独立提供价值，数据与许可边界明确 |
| 自建内核、参考并比较 SUMO | 自由违规、连续执行和统一接触等关键任务需要长期绕过其结构，已有独立库能承担基础能力 |

以上均未形成结论。无论选择哪条路线，SUMO 都可作为正常交通与交通管理语义的重要对照。独立平台不需要以“所有已有工具都做不到”为成立条件，也不追求复刻 SUMO 的全部功能。

## 5. 其他平台的位置

MetaDrive 与 Waymax 的相关设计按实际用途参考。MetaDrive 的项目维护状态本轮不作未经核验的定性，Apache-2.0 代码也不等于必须作为底座。Waymax 许可与默认数据流程按其专题说明处理。当前不因增加候选平台扩大到逐个完整复现，优先完成 SUMO 的具体问题评估。
