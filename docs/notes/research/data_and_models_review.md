# Movara 数据、决策模型与实现参考

核验日期：2026-10-30。本轮为公开来源初查，未下载候选数据、未运行实现。下列适用性是研究判断，实际接入先抽查数据。发表定位为定性说明，未核验分区与录用难度。

## 1. 数据优先级

| 数据 | 已确认的公开内容 | 建议用途 | 首要待核验项 |
| --- | --- | --- | --- |
| DUT | 自然校园环境的车人交互俯视轨迹 | 首批交互与起步事件提取候选 | 等待区间、未过街轨迹、帧率、道路与角色定义 |
| CITR | 受控车辆影响下的行人及群体轨迹 | 核验车辆影响与运动响应 | 实验指令、车辆类型、受试条件与普通道路的差异 |
| inD | 多地点路口、车辆及行人等轨迹与地图 | 路口行为、环境因素及跨地点检验 | 完整等待、过街区和行为事件是否需补标 |
| uniD | 校园共享空间的车辆、行人等轨迹与地图 | 自由交互与异质交通 | 共享空间行为如何映射到明确过街任务 |
| PIE | 连续车载视频、行为标注、部分车辆状态和意图评分 | 视觉行为证据与意图表达 | 世界坐标与全体相关对象、意图评分含义 |
| JAAD | 车载短视频、行人行为和场景标注 | 过街阶段与视觉语义补充 | 截断等待过程、车辆运动与公制几何 |

优先看 DUT/CITR 的公开轨迹能否支撑小样例，再核对 inD/uniD 的获取与场景适用性。PIE/JAAD 不作为数值环境的前置下载。暂未核对这些资源是否存在于用户其他存储位置。

本项目的数据候选与适用性在本文维护。其他项目的数据核验结果另行管理。

## 2. 数据原始来源与阅读状态

### D1. DUT 与 CITR

Top-view Trajectories: A Pedestrian Dataset of Vehicle-Crowd Interaction from Controlled Experiments and Crowded Campus，IEEE Intelligent Vehicles Symposium，2019。**发表定位：智能车辆领域重要专业会议。** 作者论文、DUT 仓库、CITR 仓库。

论文提供自然校园与受控实验两类车辆影响下的行人轨迹。**阅读范围：论文摘要和公开说明，CITR README 的数据字段部分。** CITR 提供滤波后行人与车辆轨迹、尺度说明和速度，字段语义已初查，原始文件尚未下载核验。其受控环境不能自动代表普通道路。

重点待查采集与实验条件、滤波和坐标、事件完整性及具体数据使用条件。滤波估计可能包含未来信息，在线特征构造与离线状态参考分开。

### D2. inD

官方页面、The inD Dataset: A Drone Dataset of Naturalistic Road User Trajectories at German Intersections。**文献身份：本轮核对公开预印本与官方数据页，正式发表信息待补。**

官方页面说明覆盖多个路口、车辆和行人等对象，提供轨迹和地图。**阅读范围：摘要与官方说明。** 适合世界坐标下的交互分析，申请与使用条件按实际数据发布要求核对。不能将所有弱势交通参与者数量等同于行人数，也不能假定轨迹中已有等待与起步标签。

### D3. uniD

官方页面。**资料身份：官方数据说明，本轮未核实对应论文信息。**

提供校园共享空间中的对象轨迹与道路地图。**阅读范围：官方概述、包含内容与获取入口。** 可以检查车辆对行人运动的影响，单地点覆盖与自由交互范围需要说明。数据获取和使用条件在实际接入时核对，本轮未申请或下载。

### D4. PIE

PIE: A Large-Scale Dataset and Models for Pedestrian Intention Estimation and Trajectory Prediction，ICCV 2019。**发表定位：计算机视觉主要会议主会。** 官方数据页。

包含车载视频、行人行为、相关道路元素与同步车辆信息。意图评分来自观察者实验，不是直接测得行人内心状态。**阅读范围：官方描述及论文摘要，尚未逐节复核。** 适合起步前视觉证据与意图研究，不能直接当成完整公制二维交互世界。

### D5. JAAD

官方数据页。**资料身份：官方数据与论文入口，发表类型本轮未补充核验。**

提供较短车载片段、行人框、行为与场景标注。**阅读范围：官方简介和标签说明。** 可研究过街阶段与行为证据，短片段容易截断等待，无法据其未过街直接断言始终无过街需求。实际使用前继续核对标签与划分。

## 3. 从数据到过街决策模型

首轮提取的训练单元是某名行人在过街候选区域中的连续历史与后续事件，关联当时相关车辆和地图条件。提取需要保留等待与轨迹结束，明确起步标注和不确定区间。

| 模型候选 | 可以回答什么 | 采用前需要解决什么 |
| --- | --- | --- |
| 数据校准的统计决策模型 | 哪些观测影响等待与起步 | 非线性、个体差异与重复时间样本的处理 |
| 起步时间模型 | 尚未起步时，接下来何时可能起步 | 等待时长与删失，避免只选已过街样本 |
| 小型时序策略 | 利用运动历史更新决定 | 行为持续、滚动运行和训练分布外状态 |
| 模仿或强化学习策略 | 在交互环境中执行完整行为 | 真实行为校准、奖励有效性与车辆动作变化下的适用性 |

统计学习也是数据驱动决策，首轮不要求深度网络。过去轨迹能帮助预测后续行为，反事实响应能力还需独立验证。过街中速度调整和退回等行为按数据覆盖增加。

### M1. 新近直接参考：仿真中的人类式行人策略

A Human-Like Pedestrian Model for Automated Driving Simulations，Wang 等，2026-09 预印本。公开正文。**发表状态：正文说明已投稿 IEEE，本轮未确认接收。**

该工作在部分可观测决策框架中加入感知、认知和运动约束，通过强化学习形成行人行为。**已核对摘要、方法与评价结构：** III-A 定义行人模型，III-B 说明 CARLA 与训练，III-C 区分行为、闭环和迁移评价，IV 组织相应结果。未复现代码或独立验证作者结论。

这与学习型行人仿真目标直接相关，后续应优先读观测、动作、奖励和行为校准证据。它提供复用与比较线索，不能把“行人由学习策略决策”单独认定为新方法。其训练平台不限制我们在二维环境中研究相应建模问题。

## 4. 已有交通 Agent 与模型复用

研究主体优先复用现有方法、实现和可用权重，再判断是否需要重新训练。当前未确认一个同时满足小模型、多类主体、有限观测、风格控制与任意地图泛化的通用方案，不能把候选论文称为已采用模型。

| 候选或参考 | 已查范围 | 对 Movara 的复用问题 |
| --- | --- | --- |
| SMART | 作者项目页介绍多 Agent 运动生成与公开代码入口 | 核对模型规模、权重、授权、批量推理和动作改变后的响应；作者基准成绩不直接证明 Movara 中更真实 |
| Waymax | 官方 README，基于 WOMD 的 JAX 多 Agent 研究环境 | 可参考观测/动作与闭环评价；环境本身不等同于现成小模型 |
| Nocturne | 官方 README，部分可观测的 C++/Python 驾驶环境与学习基线 | 可参考编译型内核加 Python、有限观测和模型接入；数据假设与现成权重需另查 |
| SUMO 逐车模型 | 官方模型与决策频率说明 | 作为规则参考和外围交通，不把 SUMO 简化为固定交通流 |

本轮仅查公开介绍，未逐节读完方法、下载权重、测量推理或复现成绩。上述项目提供复用线索，尚未形成模型选择结论。行人专门模型仍结合第 3 节与 DUT/CITR 数据分别研究。

采用前至少记录：主体类型、输入历史与可见信息、地图表示、动作含义、模型规模、权重与数据许可、推理设备与批次、决策频率、记忆和随机性、闭环适用范围。先复用训练模型不表示可以省去本平台中的行为验证。

激进、正常、保守先作为配置预设。共享小模型加风格条件和独立 Agent 记忆属于后续探索，多个独立模型也可以接入。模型推理按同模型主体分组，避免逐车加载权重。

### Waymax 与交通管理平台的边界

Waymax 官方说明覆盖基于 WOMD 的多 Agent 闭环、动力学接口和批量研究，不能将其概括为仅控制自车。基础环境源码展示了从日志轨迹初始化与推进的默认流程，配置定义数据与场景对象设置。

据此判断，Agent 单步协议、批量计算和动作模型与 Movara 有明显重合，值得重点借鉴。Movara 还需普通 OpenDRIVE 城市路网、持续入口交通、长期主体生命周期、违规与事故处置、原生桌面和交通管理操作。当前未验证 Waymax 直接承担这些任务的成本，不认定为现成替代，也不因研究定位不同而排除复用。

Waymax 仓库声明非商业使用条款。公开代码、数据、模型和本项目未来发布条件分别核验，当前不复制或引入其实现。

### SUMO 违规与连续运动的比较边界

SUMO 安全文档列出闯红灯、不安全换道、驾驶误差与接触配置；传送机制描述拥堵等情况下的实际传送。因此不能把所有视觉跳变都解释为显示问题，也不能把违规视为 Movara 独有能力。

用户反馈 moveToXY 在其使用场景中很难保持预期运动与接触，本轮未复现具体配置，不认定该接口普遍关闭碰撞。Movara 明确要求违规运动、连续位姿和独立于车道合法性的接触检测从底层统一支持，正常控制不依赖瞬时位置覆盖。

后续诊断找到官方已确认的 #16092，包含遥控行人横穿漏检与车道宽度映射修复，已进入 1.22.0。补丁证据与对用户具体问题尚不能归因的边界见[SUMO 评估](sumo_investigation.md#已找到的相关缺陷)。

## 6. 后续需要补齐的证据

首先补少量数据样例及字段核验，确定等待、起步和车辆响应能否被可靠提取。随后形成分组划分、简单参考与闭环评价方案。候选数据申请、下载和标注范围按实际缺口安排。

不能从这些观测数据直接得到同一真实行人在任意车辆动作下的全部结局。需要保留模型假设与适用范围，逐步建立行为校准、闭环变化与真实条件之间的证据关系。
