# Agent 信息设计调研笔记

## 6. 参考依据与阅读边界

- ETSI Cooperative Awareness，TS 103 900 V2.1.1：查阅服务介绍与收发流程，参考发送站自身状态广播的语义。
- ETSI Collective Perception，TS 103 324 V2.1.1：查阅服务与消息概述，参考分享传感器所见对象和感知范围的语义。当前不实现标准完整协议，也不声明符合标准。
- Nocturne：官方说明提供部分可观测多 Agent 驾驶环境，作为几何有限观测参考；未复现。
- OpenCOOD / OPV2V：官方项目为协同检测研究框架，可参考多来源感知与融合评价；不作为本轮内核依赖，尚未评估其模型或复用代码。
- BEVFormer：摘要介绍从多相机图像生成时空 BEV 表示，参考其表示层与观测来源的区分，本轮未复现。
- UniAD：摘要与公开说明将感知、预测和规划结合，作为 BEV 相关规划研究示例；不表示全部规划器都采用同一种表示。

本方案是针对 Movara 的设计判断，标准和研究提供职责参考，不能据此认定模型真实性、通信效果或研究新颖性已获验证。
