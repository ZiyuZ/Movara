# 行为模型

Movara 的行为建模关注车辆、非机动车与行人的闭环交互。真实数据用于校准和评价，仿真用于比较不同动作、策略和信息条件下的响应。本文说明数据、模型与评价要求，所列资源属于候选方案。

## 行为建模

主体行为分为目标与导航、行为决策和运动执行。模型输入包括允许的局部观测、地图条件和历史记忆，输出可以是行为选择、短时轨迹或运动控制。

行人模型重点描述等待、起步、过街与车辆响应。首个研究场景为一辆车与一名行人的过街交互，后续按数据覆盖扩展到多车、多人、群体影响和多车道。

轨迹预测评价记录条件下的未来运动。闭环策略评价车辆动作变化后主体的重新决策。固定轨迹重放用于数据检查和明确的回放条件。

## 数据选择

| 数据候选 | 场景与内容 | 主要用途 | 适用性检查 |
| --- | --- | --- | --- |
| DUT | 校园车人交互俯视轨迹 | 等待、起步与车辆影响 | 坐标、帧率、等待覆盖和未过街记录 |
| CITR | 受控车辆影响下的行人及群体轨迹 | 车辆影响与群体响应 | 实验指令、车辆类型、滤波与尺度 |
| inD | 路口混合交通轨迹与地图 | 路口行为与跨地点评价 | 主体分类、等待过程、地图关联和事件标注 |
| uniD | 校园共享空间轨迹与地图 | 自由交互与异质交通 | 共享空间与目标过街任务的对应关系 |
| PIE | 车载视频、行为标注与车辆信息 | 行为证据与意图研究 | 公制坐标、相关对象覆盖和意图评分语义 |
| JAAD | 车载短片段与行人行为标注 | 过街阶段与视觉语义 | 片段截断、等待覆盖和运动信息 |

初期优先评估 DUT/CITR 的交互样例，再检查 inD/uniD 的场景覆盖。视觉数据按相应研究任务使用。数据版本、获取方式和使用条件在采用时明确。

受控实验、校园和普通道路具有不同的行为分布，适用范围应包含采集条件。意图评分属于特定标注或实验结果，需要说明其含义。

## 交互样本与时间信息

行人样本包含过街候选区域中的连续历史、相关车辆、道路条件和后续事件。过街区域和起步事件需要可复查的空间与时间定义，地图标注与人工审核保留依据。

| 样本内容 | 记录要求 |
| --- | --- |
| 来源与身份 | 数据版本、片段、对象与关联车辆 |
| 运动与单位 | 时间、坐标、位置、速度及估计质量 |
| 场景条件 | 道路、候选区域、信号和交通关系 |
| 行为过程 | 接近、等待、起步、通过、停步与退回等已覆盖事件 |
| 不确定性 | 遮挡、标签区间、轨迹截断和删失 |

观察结束前尚未发生的事件采用删失标记。样本应包含未起步和未完成过街的过程，以保留等待行为的实际分布。

在线特征使用决策时刻及此前信息。完整片段可用于离线审核。使用后续帧的轨迹滤波应明确其离线估计用途。真实未来距离、未来制动和最终结果不得进入在线输入。

俯视轨迹描述世界运动估计，感知模型还需明确主体当时可用的信息。观测与记忆语义见[核心设计](core.md#agent-信息与记忆)。

## 模型选择与接入

| 模型类型 | 用途 | 评价重点 |
| --- | --- | --- |
| 统计决策模型 | 解释观测与等待、起步的关系 | 概率校准、非线性和个体差异 |
| 起步时间模型 | 估计尚未起步条件下的后续起步时间 | 等待时长、删失和事件覆盖 |
| 小型时序策略 | 利用历史与记忆持续更新动作 | 行为持续性、闭环稳定性和分布外状态 |
| 模仿或强化学习策略 | 执行完整交互行为 | 行为校准、动作变化响应和泛化 |

优先评估可复用的方法、实现和权重。SMART 等运动生成方法以及已有多主体驾驶环境可以提供局部参考。模型需要分别检查车辆、非机动车和行人的适用性。

模型接入声明输入历史、可见信息、地图表示、动作含义、更新频率、记忆、随机性、推理设备与批次。代码、权重和训练数据的使用条件分别核对。

决策周期与动作持续时间应明确。等待时间、持续行为和隐藏状态随运行保存，以保持跨 Tick 的行为一致性。

激进、正常和保守由配置预设表达。共享模型加风格条件属于候选方案。模型权重可以共享，各主体记忆与随机状态分别维护。

## 评价与实验设计

| 评价层次 | 指标与检查 |
| --- | --- |
| 预测 | 起步时间误差、概率校准、未起步覆盖和分组表现 |
| 行为分布 | 等待、接受间隙、速度调整与让行 |
| 闭环交互 | 接触、通过率、等待与通行时间、停滞和反复停走 |
| 泛化 | 独立地点、不同车辆策略与不同响应模型 |
| 数值条件 | 步长、运动约束、重复性和接触时刻 |

数据划分沿用实际训练、验证与测试协议。同一交互中的对象、密集时间窗和场景变体保持分组一致，新增划分需说明影响。

模型应在独立数据或评价条件下检查，并分析永久等待、无条件抢行和反复起停等退化行为。正常行为校准与危险场景真实性分别验证。

真实数据中的车辆减速与行人起步可能相互影响。车辆干预效果的推断需要明确模型假设、数据覆盖与敏感性分析，更强结论可以结合受控数据建立。

人工强制起步、接管和脚本动作保留来源标记。干预样本与自然行为样本分别组织。

强化学习任务将奖励、物理事实、任务终止和时间预算截断分别定义。训练与评价的信息条件需要明确，学习接口通过[核心程序接口](core.md#python-与其他程序接口)接入。
